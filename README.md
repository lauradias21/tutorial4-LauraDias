# Tutorial 4

## Purpose of the Repository
This repository was created to help me become familiar with GitHub and understand how to collaborate effectively in a shared coding environment. Through this exercise, I learned how to create and manage repositories, work with branches, make commits, review and approve pull requests, and merge changes to the main branch. These skills are essential for teamwork in future software development projects.

## Steps Taken to Complete the Tutorial
To complete this tutorial, I carefully followed the step-by-step instructions provided on Moodle. I also explored online guides to better understand how to invite a collaborator, create a feature branch, perform a pull request, and review and merge changes. Practicing these steps gave me a clearer understanding of how version control works in GitHub and how collaboration helps keep projects organized.
